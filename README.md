# WIT 战斗管理器 — Walk In the Terra

专为 **Walk In the Terra (WIT)** 明日方舟跑团规则设计的战斗管理工具，帮助主持人追踪战斗中的角色状态、伤害、元素损伤和回合顺序，节省玩家记忆空间。

## 快速启动

```bash
pip install -r requirements.txt
python main.py
```

程序关闭时自动保存所有数据到 `data.json`，v0.3 与 v1.2 使用独立单位名单，
下次启动会恢复上次使用的规则版本。

Windows 打包版将名单、战斗状态、设置和日志保存在
`%LOCALAPPDATA%\WIT-Combat-Manager\`，下载目录只需保留单个 EXE。

## 功能概览

### 角色管理
- 玩家 / 怪物统一管理，同一列表显示，类型列 + 颜色区分（蓝=玩家，红=怪物）
- 顶部可切换 v0.3 / v1.2，角色、状态和计算规则随版本切换
- 分别识别并导入 v0.3 与 v1.2 Excel 角色卡，文件版本不匹配时拒绝静默混用
- 属性：HP、速度、反应机动、双抗、SP、耐力、元素韧性、职业与骰型

### 先攻系统
| 模式 | 说明 |
|------|------|
| **v0.3 速度先攻** | 速度降序，同速比较反应机动，完全相同时由使用者填写 d100 对抗结果 |
| **传统先攻** | 逐单位填写反应机动检定总值，按检定值降序固定整场顺序 |
| **团队先攻** | 每阵营取速度最高+最低求和，高者阵营先动 |
| **客观判断** | GM 手动指定先动阵营 |

### 伤害与治疗
- v0.3 按命中 d100 与四阶段伤害公式结算，濒死检定结果由使用者填写
- v1.2 按攻击检定总值、抗性 DC、护盾和状态修正结算
- 治疗系统，禁疗 / 亲和 状态自动处理
- GM 直接输入骰娘生成的骰值或总值，程序不代替使用者掷骰
- 伤害来源与目标分离，正确结算伤害强化、脆弱、冻结和攻击后状态
- HP 归零进入濒死，溢出及后续伤害会降低生命值上限

### 元素损伤系统
- v0.3 支持 7 种元素损伤、韧性立即回满及手填 10d6 爆发总值
- v1.2 支持 6 种元素损伤与精英阶段韧性（精零=6 / 精一=9 / 精二=12）
- 韧性归零自动触发元素爆发，可当场填写来源辅助骰，也可保留待处理记录后续补结
- 爆发持续到目标自己的下个回合开始，期间及溢出损伤转为 3 倍真实伤害

### 状态效果系统
- v0.3 与 v1.2 使用各自独立的状态名称、升级链和结束时点
- **带 X 计数器**：护盾、屏障、抵抗、元素屏障、伤害强化、脆弱、失重 — 支持叠层
- **升级链**：麻痹→眩晕、寒冷→冻结、困顿→睡眠、停顿→束缚
- **标记**特殊处理：同时视为停顿/震颤/寒冷/困顿，并触发对应升级
- 按结束条件自动清理：回合结束 / 攻击后 / 受到治疗后 / X 归零

### 回合追踪
- **轮次**：场上所有单位行动一次后 +1
- **Now**：指示当前执行单位
- 状态在持有者自己的回合时点清理，爆发在持有者回合开始时恢复韧性
- 支持 迅捷 / 迟缓 回合重排序

### 规则查询
- `Ctrl+K` 打开非模态规则查询窗口
- 可按版本与分类筛选规则、职业和源石技艺
- 在本地读取规则书 Excel 工作簿，只显示命中的结构化条目，不复制整份规则资料

### 规则书路径设置
规则书（PDF）与配套 Excel 工作簿为 CC BY-NC-SA 4.0 许可，**程序本身不含任何规则内容**，需要用户自行下载规则书文件并在本地设置：
- **规则书路径（Excel）...**（更多菜单）：选择存放 4 份工作簿的目录，程序会按文件名自动识别 `角色卡 行于泰拉v0.3 (1).xlsx`、`v1.2.战斗职业（非法术部分）.xlsx`、`v1.2源石技艺.xlsx`、`v1.2.角色卡.Plus .xlsx`（不区分大小写），并在规则查询窗口中提供规则、职业、源石技艺搜索；目录缺失文件时会列出所需文件名提示
- **打开规则书（PDF）...**（更多菜单）：选择规则书 PDF 后用系统默认程序打开；下次点击直接打开已保存的路径
- 设置保存在 `settings.json` 中，重启后自动恢复
- 职业下拉候选、规则查询数据均来自用户设置目录中的工作簿；未设置时规则查询显示“未配置规则书”提示，职业下拉仍可手动输入

## 项目结构

```
wit-combat-manager/
├── main.py              # 入口
├── models.py            # Unit / CombatState 数据模型 + 状态常量表
├── combat.py            # 伤害 / 治疗 / 元素损伤 / 状态升级 / 回合管理
├── combat_v03.py        # v0.3 独立规则实现
├── character_card.py    # 两版角色卡识别与导入
├── rule_catalog.py      # 规则 / 职业 / 源石技艺查询索引
├── persistence.py       # JSON 持久化
├── ui/
│   ├── main_window.py   # 主窗口（左右分栏 + 战斗日志）
│   ├── unit_panel.py    # 单位列表 + 筛选 + 详情
│   ├── unit_dialog.py   # 添加/编辑弹窗
│   ├── combat_panel.py  # 先攻 / 伤害输入 / 元素损伤 / 状态操作
│   └── rule_browser.py  # 规则查询窗口
├── 工作资料/            # 规则参考文件（不上传）
│   ├── buff.txt
│   └── 元素损伤.txt
└── README.md
```
